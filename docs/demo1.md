# Демо 1. Publish / Subscribe через CLI

Время: около 5 минут. Слайд 25.

Показываем три модели взаимодействия со слайда 11 живьём и заканчиваем тем, что базовый NATS
сообщения не хранит, — это мост к JetStream.

## Подготовка

```bash
cd ~/Documents/Java/nats-demo
./up.sh        # до эфира
./box.sh       # вход в контейнер с CLI
```

Внутри контейнера:

```sh
/demo/t3.sh
```

Терминал делится на три панели: слева вверху `SUB A`, справа вверху `SUB B`, внизу широкая `PUB`.
Панели переключаются мышью или `Ctrl-b` со стрелкой.

## Шаг 1. Одно сообщение получают все подписчики

В панелях `SUB A` и `SUB B`:

```sh
nats sub "orders.>"
```

В панели `PUB`:

```sh
nats pub orders.created '{"id":1001,"sum":250}'
```

Обе верхние панели показывают одно и то же сообщение:

```
[#1] Received on "orders.created"
{"id":1001,"sum":250}
```

## Шаг 2. Queue Group: сообщение достаётся одному

`Ctrl-C` в обеих верхних панелях, затем в каждой:

```sh
nats sub "orders.>" --queue workers
```

В панели `PUB`:

```sh
for i in 1 2 3 4 5 6; do nats pub orders.created "order-$i"; sleep 1; done
```

Сообщения расходятся между двумя подписчиками, каждое достаётся ровно одному. Распределение
случайное, поэтому счёт бывает не поровну: на шести сообщениях обычно выходит четыре и два или
три и три.

## Шаг 3. Request / Reply

`Ctrl-C` в панели `SUB B`, затем поднимаем там сервис-ответчик:

```sh
nats reply svc.price "цена заказа {{.Request}}: 250 руб"
```

В панели `PUB`:

```sh
nats request svc.price "1001"
```

Ответ возвращается тому, кто спрашивал:

```
цена заказа 1001: 250 руб
14:39:39 Received with rtt 987.083µs
```

## Шаг 4. Без подписчиков сообщение исчезает

`Ctrl-C` в обеих верхних панелях. В панели `PUB`:

```sh
nats pub orders.created "это сообщение никто не ждёт"
```

Теперь поднимаем подписчика в `SUB A`:

```sh
nats sub "orders.>"
```

Панель молчит: подписчик, который пришёл после публикации, сообщения не получит. Базовый NATS
доставляет только тем, кто подключён прямо сейчас. Чтобы сообщения сохранялись, нужен JetStream —
это демо 2.

`Ctrl-C`, панели остаются открытыми, они пригодятся дальше.
